## 📖 О проекте

**CosmosBlackHole** — это научно-исследовательская веб-утилита, позволяющая рассчитывать и в реальном времени визуализировать процессы зарождения чёрных дыр (звёздного коллапса, первичных чёрных дыр ранней Вселенной и прямых коллапсаров) при варьировании фундаментальных физических констант и космологических параметров.

В качестве эталона приняты параметры **Нашей Вселенной** (измерения космической обсерватории *Planck 2018* и комитета *CODATA*), в которой сформировались условия для звёздного нуклеосинтеза, долгоживущих планетных систем, возникновения жизни и сознания.

Симулятор объединяет аналитический вывод астрофизических пределов из первых принципов, 3D-рендеринг релятивистского искривления пространства-времени, фазовые диаграммы антропных зон и академическое досье с математическими доказательствами.

## 🚀 Основной функционал

### 1. Интерактивное управление фундаментальными константами
Вы можете плавно изменять параметры Вселенной в логарифмическом масштабе ($X / X_{\text{наша}}$):
- **$G$** — Гравитационная постоянная (интенсивность тяготения и глубина гравитационной воронки).
- **$c$** — Скорость света в вакууме (релятивизм, эквивалентность массы и энергии $E=mc^2$).
- **$\hbar$** — Приведённая постоянная Планка (квантовое действие, давление вырождения фермионов).
- **$\alpha$** — Постоянная тонкой структуры (электромагнетизм, размеры атомов, резонанс Хойла).
- **$m_p$** — Масса покоя протона (плотность вещества и гравитационная масса ядер).
- **$m_e$** — Масса покоя электрона (радиус Бора, релятивистский порог вырождения).
- **$\Lambda$** — Космологическая постоянная (плотность тёмной энергии вакуума, ускорение расширения).
- **$Q$** — Амплитуда первичных флуктуаций плотности после инфляции ($\delta\rho/\rho$).

Метрики мгновенно пересчитываются с отображением относительного коэффициента ($\times$), абсолютного значения в системе СИ и дельты ($\Delta\%$) относительно Нашей Вселенной.

### 2. 3D-визуализация релятивистской ЧД (WebGL / Three.js)
Интерактивная сцена искривлённого пространства-времени вокруг чёрной дыры:
- **Горизонт событий ($r_s = 2GM/c^2$)**: Абсолютно чёрная сфера Шварцшильда, поглощающая падающее излучение.
- **Фотонная сфера ($r_{ph} = 1.5 r_s$)**: Тонкое гравитационное кольцо Эйнштейна с оптическим преломлением.
- **Аккреционный диск с релятивистским доплеровским свечением**: Динамическая система из 20 000 частиц с дифференциальным кеплеровским вращением ($v \propto r^{-1/2}$). Сторона диска, вращающаяся по направлению к наблюдателю, испытывает доплеровское усиление яркости и синее смещение, а удаляющаяся — ослабление и красное смещение.
- **Гравитационное линзирование дуг**: Характерный оптический эффект искривления задней части диска над и под горизонтом (эффект фильма *Интерстеллар* и снимков *Event Horizon Telescope*).
- **Пространственно-временная сетка (Воронка Шварцшильда)**: Деформируемая координатная плоскость, наглядно показывающая кривизну гравитационного колодца в зависимости от $G$.
- **Переключение массы**:
  - *Микро-PBH ($10^{12}$ кг)* — с ярким квантовым гало излучения Хокинга.
  - *Звёздная ($10 M_\odot$)* — типичная чёрная дыра звёздного коллапса с аккреционным диском.
  - *Sagittarius A\* ($4.15 \times 10^6 M_\odot$)* — сверхмассивная чёрная дыра в центре Галактики.

### 3. Интерактивная 2D-фазовая диаграмма антропных зон
Диаграмма устойчивости материи и жизни в зависимости от соотношения констант:
- **Срез «$\alpha$ vs $\alpha_G$»**: Электромагнитная связь против гравитационной связи протонов.
- **Срез «$G$ vs $\Lambda$»**: Гравитационное стягивание против разрыва тёмной энергией.
- **Выделенные физические области**:
  - 🟢 **Антропная зона (Жизнь и разум)** — баланс констант, устойчивые атомы, горение звёзд $\ge 1.5$ млрд лет.
  - 🔴 **Зона доминирования ЧД** — сверхсильное тяготение, мгновенный коллапс вещества до формирования планет.
  - 🟣 **Зона радиационной нестабильности** — лучистое давление разрывает протозвёзды.
  - 🔵 **Зона холодного газа** — гравитация слишком слаба для преодоления предела Джинса.
- **Навигация**: Фиксированная золотая звезда Нашей Вселенной и анимированный пульсирующий маркер текущей модели с вектором отклонения.

### 4. Спектр масс ЧД ($dN / d\log M$) и Космическая хроника
- **Спектр масс**: Логарифмический график распределений первичных чёрных дыр (PBH) и звёздных коллапсаров с динамической линией границы испарения Хокинга ($M_{\text{evap}}(t_0)$).
- **Космическая хроника**: Временная шкала эволюции Вселенной от Планковской эры и инфляции до Эры Чёрных Дыр и их испарения, динамически адаптирующаяся под время жизни звёзд и пороги коллапса.

### 6. Библиотека космологических сценариев (Пресеты)
- **Наша Вселенная ($\Lambda$CDM)** — точные параметры Planck/CODATA, умеренное число ЧД, развитая жизнь.
- **Мультивселенная Смолина (CNS)** — максимальное размножение через сингулярности ЧД ($G \times 1.8$, $Q \times 6.0$).
- **Гипергравитационный коллапс (Super-G)** — $G \times 10$: звёзды сгорают за миллионы лет и схлопываются в ЧД.
- **Беззвёздная холодная Вселенная** — ослабленный $G$ ($0.1\times$) и завышенная $\Lambda$ ($50\times$), звёзды не зажигаются.
- **PBH-Доминантная Вселенная** — сверхвысокий $Q$ ($50\times$): ранняя Вселенная целиком сколлапсировала в реликтовые ЧД.
- **Квантово-доминантная Вселенная** — $\hbar \times 4$: гигантское давление вырождения, предел Чандрасекара достигает сотен $M_\odot$.
- **Вселенная без слабого взаимодействия (Weakless Universe)** — модель Харника-Крибса-Переса.

## 📐 Ключевые физические формулы

| Параметр / Предел | Формула | Физический смысл |
|---|---|---|
| **Предел Чандрасекара** | $M_{\text{Ch}} \approx \frac{\omega_3^0 \sqrt{3\pi}}{2} \left(\frac{\hbar c}{G}\right)^{3/2} \frac{1}{(\mu_e m_p)^2} \propto \alpha_G^{-3/2} m_p$ | Верхний предел массы белого карлика, поддерживаемого давлением релятивистского вырожденного электронного газа ($1.44 M_\odot$). |
| **Предел TOV** | $\frac{dP}{dr} = -\frac{G M \rho}{r^2} \left(1 + \frac{P}{\rho c^2}\right)\left(1 + \frac{4\pi r^3 P}{M c^2}\right)\left(1 - \frac{2GM}{c^2 r}\right)^{-1}$ | Релятивистское уравнение гидростатического равновесия. Задаёт предел массы нейтронной звезды ($2.16 M_\odot$). |
| **Радиус Шварцшильда** | $r_s = \frac{2GM}{c^2}$ | Радиус сферы горизонта событий невращающейся чёрной дыры. |
| **Фотонная сфера** | $r_{ph} = \frac{3GM}{c^2} = 1.5 r_s$ | Радиус круговой орбиты фотонов вокруг ЧД, формирующий кольцо Эйнштейна. |
| **Формализм Пресса-Шехтера (PBH)** | $\beta(M) = \frac{1}{2} \operatorname{erfc}\left( \frac{\delta_c}{\sqrt{2}\sigma_Q} \right)$ | Доля ранней Вселенной, сколлапсировавшая в первичные чёрные дыры при входе под горизонт ($\delta_c \approx 0.45$). |
| **Температура Хокинга** | $T_H = \frac{\hbar c^3}{8\pi G M k_B}$ | Квантовое тепловое излучение горизонта событий чёрного тела. |
| **Время испарения Хокинга** | $\tau_{\text{evap}} = \frac{5120 \pi G^2 M^3}{\hbar c^4}$ | Полное время квантового испарения чёрной дыры до финального гамма-взрыва. |
| **Гравитационная связь протонов** | $\alpha_G = \frac{G m_p^2}{\hbar c} \approx 5.906 \times 10^{-39}$ | Безразмерное отношение силы гравитационного притяжения к квантовой шкале. |
| **Число Риса $N$** | $N = \frac{\alpha}{\alpha_G} \approx 1.23 \times 10^{36}$ | Отношение электрического отталкивания к гравитационному притяжению протонов. |
| **Время жизни звезды** | $\tau_* \sim 10^{10} \text{ лет} \times \left(\frac{\alpha_0}{\alpha}\right)^2 \left(\frac{\alpha_{G0}}{\alpha_G}\right) \left(\frac{c_0}{c}\right)^3$ | Время жизни солнцеподобной звезды на главной последовательности. |

## ⚙️ Инструкция по установке и запуску

### Требования
- Установленный [Node.js](https://nodejs.org/) (версии **18.x** или выше).
- Менеджер пакетов `npm` (версии **9.x** или выше).

### 1. Клонирование репозитория (или переход в папку)
```bash
git clone https://github.com/iddqd-create/cosmos-black-hole-simulator.git
cd cosmos-black-hole-simulator
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера для разработки
```bash
npm run dev
```
После запуска в терминале появится ссылка на локальный сервер:
👉 **`http://localhost:5173/`**

Откройте её в любом современном браузере (Chrome, Firefox, Safari, Edge).

### 4. Запуск тестов физического движка
Для проверки корректности математических расчетов запустите:
```bash
npm test
```
Тестовый набор проверяет 21 физический инвариант (пределы Чандрасекара, TOV, гравитационную связь, время жизни Хокинга и пресеты).

### 5. Сборка для публикации (Production Build)
```bash
npm run build
```
Готовые оптимизированные статические файлы будут скомпилированы в директорию `dist/`.

Для предварительного просмотра сборки выполните:
```bash
npm run preview
```
